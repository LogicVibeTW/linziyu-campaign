# 行程照片資料夾

把「子宇去哪兒」行程要顯示的照片放在這裡。

## 使用方式
1. 把照片檔案上傳到這個資料夾（GitHub 網頁介面：進到這個資料夾 → Add file → Upload files）
2. 檔名建議用英文/數字，不要有空格（例如 `2026-08-13-fude.jpg`）
3. 到 Google 試算表 Schedule 分頁，在對應那一列的 `image_url` 欄位，直接填「檔名」就好
   - 例如：`2026-08-13-fude.jpg`
   - 不需要填完整網址，網站會自動組合
4. 上傳照片後記得也要一起 commit，Vercel 才會重新部署、圖片才會生效

如果 image_url 欄位填的是完整網址（http 開頭），網站也會照樣直接使用該網址（保留彈性，例如未來想改用其他圖床）。
